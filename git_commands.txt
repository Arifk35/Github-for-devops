1. git init
2. git status
3. git add  -> untracked to staged
4.git commit -m " " -> staged to unstaged
5.git rm --cached <file> -> staged to untracked
6.git restore

# For creating repository from terminal in github command
Public repository
7. gh repo create Github-for-devops --public --source=. --remote=origin --push

Private repository
8. gh repo create Github-for-devops --private --source. --remote=origin --push

command ka use local Git repository ke saath connected remote repositories (GitHub/GitLab) ke URLs check karne ke liye hota hai.
9. git remote -v 

command ka use local Git repository se code ko remote repository (GitHub) ke master branch par upload karne ke liye hota hai.
10. git push origin master 

git pull GitHub (remote) se latest changes download karke aapki local branch mein merge karta hai. Matlab: git push local se GitHub pe bhejta hai, git pull GitHub se local pe laata hai.
11. git pull origin main
